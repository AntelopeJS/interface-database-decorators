## Overview

`@antelopejs/interface-database-decorators` describes tables as TypeScript classes and reads and writes converted rows through models. It builds on AQL (`@antelopejs/interface-database`) and adds field modifiers and model injection into API controllers.

## From a table class to a stored record

1. **Describe the table.** Extend `Table`, declare fields and indexes, and register the class with `@RegisterTable("users", "myapp")`. See [table definitions](./2.table-definitions.md).
2. **Bind the schema.** Import the table declarations, then call `await RegisterSchema("myapp")` from their declaring module. The call needs a configured database module. It provisions the tables and inserts fixtures, so it writes to the database.
3. **Create the model.** Use `BasicDataModel(User)` with a `SchemaInstance`, or call `GetModel` once the table is bound. See [data models](./4.data-models.md).
4. **Write and read through the model.** Model operations apply the conversions and the modifier events. To compose an AQL query yourself, use `model.table`.

Keep schema IDs and instance IDs apart. `myapp` names the table definitions, and an instance ID selects the database instance a model uses. `GetModel` throws for a table class that `RegisterSchema` has not bound, unless a schema of the class's schema name already exists.

### Save and retrieve a note

In a module with a configured database module, import this declaration, then call `tryNote()` during initialization. Use a disposable development database, because `RegisterSchema` provisions the schema and `insert` writes a row.

```ts docs-check
import {
  BasicDataModel,
  Field,
  GetModel,
  RegisterSchema,
  RegisterTable,
  Table,
} from "@antelopejs/interface-database-decorators";

@RegisterTable("notes", "notes-demo")
class Note extends Table {
  @Field("string")
  declare title: string;
}

class NoteModel extends BasicDataModel(Note) {}

export async function tryNote() {
  await RegisterSchema("notes-demo");
  const notes = GetModel(NoteModel);
  const [id] = await notes.insert({ title: "Learn models" });
  const saved = await notes.get(id);
  if (!saved) throw new Error("The inserted note was not found");
  return saved.title; // "Learn models"
}
```

The model uses the default instance of the schema bound to `Note`. Each run inserts a new note, so keep the inserted ID if you extend this exercise with `update` or `delete`. In an application, register the schema once during initialization, not on each request.

## Choose the layer for your task

| Task                                | Layer                                               | Important boundary                                               |
| ----------------------------------- | --------------------------------------------------- | ---------------------------------------------------------------- |
| Describe storage fields and indexes | [Table definitions](./2.table-definitions.md)       | Declaring a class is separate from registering its schema.       |
| Encrypt, hash, or localize fields   | [Table modifiers](./3.table-modifiers.md)           | Conversion events determine when transformations run.            |
| Read or write converted records     | [Data models](./4.data-models.md)                   | Reads return converted records, not chainable queries.           |
| Select a model in an HTTP request   | [Parameter decoration](./5.parameter-decoration.md) | The instance ID selects a binding. It does not authorize access. |

Start without modifiers until the schema and the model work together. Validation is opt-in. A string-token `@Field` describes storage only, and codec validation needs io-ts codecs and the model's `validate` option.

## Dependencies

The package depends on these packages:

- [`@antelopejs/interface-database`](https://github.com/AntelopeJS/interface-database) is the database query interface (AQL).
- [`@antelopejs/interface-api`](https://github.com/AntelopeJS/interface-api) provides the API controllers that `@Model` injects into.
- [`@antelopejs/interface-core`](https://github.com/AntelopeJS/interface-core) provides the decorator factories.
- [`reflect-metadata`](https://www.npmjs.com/package/reflect-metadata) stores the decorator metadata.
- [`randomstring`](https://www.npmjs.com/package/randomstring) generates the salt of a `@Hashed` field that sets an `algorithm`.
